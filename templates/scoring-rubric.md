# Scoring rubric (0–10)

| Score | Meaning | Evidence weight |
|---|---|---|
| 0 | Not attempted | none |
| 1–2 | Attempted; wrong or doesn't run | none |
| 3–4 | Runs only on the happy path; key concept misunderstood | none |
| 5–6 | Works; gaps in error handling, tests, or reasoning | weak |
| 7–8 | Correct, tested, and the user can explain *why* | counts toward `proven` |
| 9–10 | Correct, clean, tested, and production-ready, or teaches back clearly | strong `proven` |

**Dimensions to check** (pick what fits): correctness · tests · error handling · design or trade-off reasoning · ops-readiness (config, logs, health) · explanation without AI help.

**Rule:** say the score first, then one reason, then one fix.
