# Routine prompt: soft-skills day

Run `docs/workflows/soft-skills-friday.md`.

- Start with the short quiz: `docs/workflows/weekly-quiz.md` in short mode (3–5 questions, about 15 minutes).
- Review and score last week's soft-skills exercise.
- Teach this week's topic from the soft-skills plan in `profile/roadmap.md`: one framework or script, with its source.
- Run the role-play with `templates/role-play.md`, then debrief with a score, the best line, and one better line.
- Create next week's real-world exercise as a task due on the next soft-skills day.
- Log to `profile/changelog.md`. Move a soft-skill level only on real-world evidence.
