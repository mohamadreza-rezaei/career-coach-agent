# Routine prompt: monthly Platform Sync

Run `docs/workflows/platform-sync.md`.

- List the skills that became `proven` since the last sync, and the contradictions this resolves.
- Draft one small patch per surface with `templates/surface-patch-proposal.md`.
- Send a single approval message. Apply only approved patches on `write-with-approval` surfaces, and hand hint-only text to the user.
- Update `profile/contradictions.md` and `profile/changelog.md`, and queue a brain delta.
- If this is before the first checkpoint in `profile/roadmap.md`, propose only factual contradiction fixes.
