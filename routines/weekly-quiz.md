# Routine prompt: weekly quiz

Run `docs/workflows/weekly-quiz.md`.

- Build 5–8 questions from this week's lessons, weighted to the weak spots, using `templates/quiz.md`.
- Send them and wait for the answers. Score each 0–10 with `templates/scoring-rubric.md`.
- Patch `profile/skill-model.md` only where there's new evidence, and add a changelog line.
- Propose next week's order on each track.
- If a level moved or a milestone was hit, queue a brain delta.
