# Routine prompt: daily lesson

Run `docs/workflows/daily-lesson.md` for today in `COACH_TIMEZONE`.

- Read `profile/schedule.md` to get today's track. If today is the quiz and soft-skills day, run `docs/workflows/soft-skills-friday.md` instead (it includes the short quiz). If it's a rest day or an override says so, send nothing.
- Score yesterday's task 0–10 with evidence (the task status, linked commits, the user's reply).
- Teach one concept and give one drill toward this month's milestone in `profile/roadmap.md`.
- Create today's task in that track's sub-project.
- If there's an open security item, add one line about it.
- Reply in the user's language, within one screen, using `templates/daily-message.md`.
- If nothing is new and nothing is due, stay quiet.
