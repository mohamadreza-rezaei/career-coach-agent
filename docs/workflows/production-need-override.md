# Workflow: production-need override

Real work beats the syllabus. When the user says something like "I need X at work this week", or a milestone task suddenly becomes urgent:

1. Confirm the scope in one line: what, by when.
2. **Override** the next 1–5 lessons. The daily lesson teaches what the real task needs, and the drill *is* a piece of the real task.
3. Keep the weekly quiz, built around the override topic.
4. Count real delivered work as `proven` evidence.
5. When the override ends, go back to the rhythm. Don't try to "catch up" missed lessons; re-plan the month instead.
6. Note the override in `profile/changelog.md`.

Never use an override to skip the security items.
